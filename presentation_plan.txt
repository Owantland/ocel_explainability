4) Explainability layer - Most important part
	Present the layer as a FOUR-component approach (not three): LOO, Fidelity metrics,
	Feature attribution, and Counterfactual explanation. Use
	Hetero_GNNs_with_Post_Hoc_Explanations (Zhai et al. 2025) as the template followed
	Explain LOO methodology and benefits
		- LOO now reports a SIGNED shift alongside the existing magnitude (2026-07-06
		  addition): signed_shift = baseline_value - perturbed_value. Positive means
		  the element's real value pushed the prediction toward a LONGER remaining
		  time than the substitute used when "removing" it; negative means SHORTER.
		  Methodological caveat to state explicitly when presenting this: node
		  features are z-score normalized (training.py), so "removing" a value means
		  replacing it with the training-set MEAN, not a neutral/absent baseline -
		  the sign should be framed as "this element's value, relative to the
		  population average, pushed the prediction up or down," not as an absolute
		  causal claim. Ranking, the >1 std "large shift" flag, and Fidelity+/-/
		  Characterization all deliberately continue using the unsigned magnitude
		  (direction-agnostic by design - a -283h effect is exactly as important as a
		  +283h one); only the per-trace display (console, CSVs, and the subgraph/
		  bar-chart colors) is signed. Aggregate LOO (n=50 traces) also stays
		  magnitude-only, since averaging signed values across differently-behaved
		  orders would risk cancellation masking real impact.
	Explain Fidelity metrics (Fidelity+/Fidelity-/Characterization/sparsity) as their own item
		- Grounds the "are these explanations trustworthy" question in Stevens et al. (2022)'s
		  faithfulness framework - likely to be asked directly, deserves explicit treatment
		  rather than being folded silently into the LOO section
	Explain feature attribution based on the original paper's design (InputXGradient /
	IntegratedGradients via Captum)
		- Show the depth-stratified heatmap (prefix-depth-bin x feature-dim) as this
